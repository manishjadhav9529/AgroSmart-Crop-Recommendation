# 🌱 AgroSmart – ML-Driven Crop Recommender

## 🔍 Introduction
AgroSmart is a machine learning-based agricultural application that helps farmers make better farming decisions. It analyzes soil and environmental conditions to recommend suitable crops, predict crop yield, and suggest fertilizers. The system also integrates weather information and data visualization to support smart and sustainable agriculture.

## 🎯 Features
- **Crop Recommendation:** Recommends suitable crops using the Random Forest algorithm.
- **Yield Prediction:** Estimates crop yield using a Decision Tree model.
- **Fertilizer Recommendation:** Suggests suitable fertilizers using Random Forest.
- **Weather Information:** Fetches real-time weather data using the OpenWeatherMap API.
- **Language Translation:** Provides multilingual support using the Google Translate API.
- **Data Visualization:** Displays agricultural insights through bar graphs and pie charts.

## 💻 Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask, PHP
- **Machine Learning:** Random Forest, Decision Tree
- **APIs:** OpenWeatherMap API, Google Translate API
- **Datasets:** Kaggle agricultural datasets for crop recommendation, fertilizer recommendation, yield prediction, and analysis.

## ⚙️ How It Works
1. Users enter relevant soil and environmental information.
2. Machine learning models analyze the input data.
3. The system recommends suitable crops and fertilizers and estimates crop yield.
4. Weather information is retrieved through the weather API.
5. Visual charts present useful agricultural insights to help users make informed decisions.

## 🌾 Conclusion
AgroSmart combines machine learning and agricultural data to support crop selection, yield prediction, and fertilizer recommendations. The project aims to improve farming decisions, resource utilization, and sustainable agricultural practices.
